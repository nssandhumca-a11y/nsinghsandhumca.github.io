1. Course Overview

PGDCA (Post Graduate Diploma in Computer Applications) is a one-year professional diploma programme offered by Government Degree College Chamba under Himachal Pradesh University, Shimla.

Main Objectives of the Course 1. To develop fundamental and advanced computer knowledge. 2. To provide practical programming skills. 3. To understand computer hardware and software. 4. To develop database management skills. 5. To learn web designing and development. 6. To develop problem-solving and logical thinking abilities. 7. To prepare students for employment in the IT sector. The course is designed to develop computer knowledge, programming skills, software applications, database management and practical IT skills. Government College Chamba offers PGDCA under its self-finance programmes, with 30 seats listed on its college profile.

Broad Learning Outcomes

  • Design and build structured, responsive web pages and introductory web applications.
  • Explain fundamental AI concepts and develop simple Python-based learning activities.
  • Describe IoT architecture and demonstrate how sensors and connected devices exchange data.
  • Identify major computer hardware components and perform basic diagnostic and maintenance tasks.
  • Explain data communication principles, network models, devices and common protocols.
  • Apply problem-solving, documentation, safe computing and responsible technology practices.

2. Learning Resources

Use these resources as a starting point for classroom study, demonstrations and laboratory practice.

Web Designing & Web Applications

  • HTML structure, forms, tables and semantic elements
  • CSS styling, layouts and responsive design
  • JavaScript fundamentals and DOM interaction
  • Code editor, browser developer tools and GitHub Pages
  • Mini project: personal or departmental website

Artificial Intelligence & IoT

  • Introduction to AI, machine learning and applications
  • Python basics and introductory AI demonstrations
  • IoT architecture, sensors, actuators and connectivity
  • Microcontrollers and IoT simulation / practical tools
  • Mini project: simple smart-monitoring concept

Computer Hardware

  • Motherboard, CPU, RAM and storage devices
  • Input, output and peripheral devices
  • Power supply, ports and expansion cards
  • Assembling, disassembling and safety precautions
  • Mini task: hardware identification and diagnosis

Communication Networking

  • Data communication components and transmission media
  • Network topologies, LAN, MAN and WAN
  • Hub, switch, router, modem and access point
  • OSI and TCP/IP models; IP addressing basics
  • Mini task: design and test a small LAN

Study approach: Read the topic, observe a demonstration, complete a guided practical, record the result and explain what you learned. Use AI tools responsibly and verify generated information.

Suggested Project Options

  • Develop a responsive website for a course, department or local information resource.
  • Create a Python-based introductory AI demonstration or documented AI use-case study.
  • Prepare an IoT smart-monitoring prototype or simulation with a block diagram.
